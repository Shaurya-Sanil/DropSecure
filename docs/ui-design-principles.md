# AI Masterclass: UI/UX Design Prompts & Checklist

**Purpose:** A curated list of design principles to use as prompts for AI UI generators or as a manual checklist for improving app interfaces. 

> **Important Note:** Not all of these principles need to be used for every single app. Context is key! Select and apply these rules based on the specific goals, audience, and constraints of your current project.

## 📐 Layout & Spacing
* **Group with spacing:** Use white space to group related elements naturally instead of relying on borders.
* **Enlarge the Main feature:** Make sure the core functionality or primary feature is the most visually dominant element.
* **Align by eye, not pixels:** Optical alignment often looks better than strict mathematical alignment.
* **Inner radius = outer - padding:** Keep border radii mathematically harmonious for nested elements.

## ✍️ Typography & Content
* **Make headings specific:** Avoid generic titles; tell the user exactly what the section is about.
* **Wrap headlines properly:** Avoid awkward widows or unbalanced text blocks in your headers.
* **Mono only where needed:** Reserve monospace fonts for code, data, or specific labels, not body text.
* **Unitalicize random words:** Keep emphasis deliberate and minimal to avoid a messy look.
* **Use tabular nums:** Ensure numbers in tables, pricing, or data lists align perfectly vertically.

## 🎨 Visual Styling & UI Elements
* **Use a design system:** Ensure consistency by pulling from a defined set of variables and components.
* **Emphasize the CTA:** Make your Call to Action impossible to miss.
* **Add an accent colour:** Use a single, strong accent color to draw the eye to interactive elements.
* **Keep icons consistent:** Ensure stroke width, style, and corner radii match across all icons.
* **Improve text contrast:** Ensure all text passes accessibility standards against its background.

## ✂️ Minimalism (What to Remove)
* **Delete filler badges:** Remove unnecessary "New" or "Hot" tags if they don't add real value.
* **Drop redundant labels:** If an icon or context makes the function obvious, remove the text label.
* **Remove embellishments:** Strip away unnecessary drop shadows, gradients, and borders if they don't serve a purpose.

## ⚙️ UX & Interaction
* **Show the actual product:** Use real data, screenshots, or mockups rather than abstract illustrations when possible.
* **Add loading states:** Use skeleton loaders or spinners to keep the user informed during wait times.
* **Animate useful feedback:** Use micro-interactions to confirm user actions (like a subtle bounce on a successful button click).
